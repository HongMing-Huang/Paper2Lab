4. 执行本次所需检查：类型/schema、定向测试、实际内核或供应商回合；UI改动再做单浏览器真实操作/Console。先隔离研究上游测试收集，保留本项目全部产品测试。阶段收口按固定集合运行测试/build，不因失败临时缩小集合、skip或放宽阈值。
5. 冻结diff/文件身份，调用独立只读reviewer复核合同、代码、负例及证据。审阅期间不改冻结范围；有修正则复核增量。没有独立review能力就保持verifying，不能主Agent自行签独立通过。
6. 只有实现、必要验证、独立review全部过才更新子项done。父项及C1/E1/E2另验集成，不自动勾选。保存精简证据路径和下一动作，重算ready，继续下一个必要子项；不每步停下来问“是否继续”。
