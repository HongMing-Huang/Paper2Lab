# xGPU 乐园（xGPU-Explorers）加入申请 —— Paper2Lab 可执行论文平台

## 申请理由（可直接粘贴到组织申请/后台留言）

我是在校开发者，正在建设一个名为 **Paper2Lab（可执行论文）** 的开源 AI 应用，希望加入「xGPU 乐园」组织获得 xGPU Beta 资源，把这个已经跑通的项目部署为社区可公开体验的创空间。

**项目是什么**
Paper2Lab 把一篇数学 PDF 论文变成"可以操作的论文"：Docling 解析论文 → 公式经 Cortex Compute Engine 编译成可交互实验 → 用户直接拖动参数/抓取 3D 物体，图表与观测由真实科学内核（自研 Kakeya 体素引擎、MuJoCo WASM 物理社区演示、RK4/LV 常微分方程内核）即时重算，每个数字都可溯源到 ExperimentRun；内置 Research Agent（基于 AgentScope 外部执行协议）能与用户在同一约束下做对比实验。项目已开源（GitHub 私仓转公开中），全链路真实计算、无任何模拟数据。

**为什么需要 xGPU**
当前创空间（https://modelscope.cn/studios/Jack0702/paper2lab，CPU 2v/8g 免费档）已部署并运行，但存在两点 GPU/调度限制：
1. 免费实例的函数计算调度会冻结后台子进程，导致引擎首次调用 504——需要更稳定的算力保障常驻推理服务；
2. 下一步计划加入的三关挑战（物理仿真落点、摆周期匹配、管束压缩）与后续论文案例（偏微分方程数值解、傅里叶算子学习演示）在 CPU 上推理延迟过高，GPU 加速可将单次实验响应从分钟级降到秒级，显著改善可玩性。

**对社区的价值**
- 创空间将保持公开，任何社区用户可直接体验"论文变实验"的完整流程；
- 沉淀的部署技能与踩坑文档（Docker 型创空间 + FastAPI + Node 引擎混合栈）会整理成教程回馈社区；
- 项目本身是"AI for 科学教育"方向，与魔搭社区生态契合。

**承诺**：资源仅用于该开源项目的社区演示与开发迭代，遵守平台规则；如获得 GPU 资源，会在项目主页致谢魔搭 xGPU 乐园，并持续维护。
